# Chess2 — HTML Chess Tutorial Websites

The ZIP files here contain complete HTML chess tutorial websites, with thousands of tutorial pages across the collections. Download and extract an archive to browse its lessons locally.

## How to use the websites

1. Open an archive's file page and select **Download raw file**, or use **Code → Download ZIP** for the whole repository.
2. Extract the downloaded ZIP. If you downloaded the repository ZIP, extract the individual course ZIPs inside it as well.
3. Follow any included starting guide. Open `index.html` if present, or another lesson HTML file, in a browser.
4. Keep the extracted folder structure intact so links and supporting files can resolve.

## Changes and protection

The default branch is protected against force pushes and branch deletion. Changes go through a pull request, with no user or app bypass exemptions. Independent review approval is not required, so the owner can maintain the library without another collaborator.

Files can still be edited or deleted through a merged pull request. The owner can change the protection rules or delete the entire repository. Keep a local copy of material you want to retain.

## Use and corrections

Follow the licenses, credits and reuse instructions included with each collection. If you find an error, identify the course, file, page or section, and the move or explanation that needs correction.
